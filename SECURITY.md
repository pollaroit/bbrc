# Security

BBRC is a private reading-club application. **Do not open public GitHub issues** for vulnerabilities, leaked credentials, or member data exposure.

Email **mehdi.asadli@pollaroit.com** with:

- What you found and where (route, feature, or component)
- Steps to reproduce (minimal)
- Whether production or local dev was affected

We will acknowledge as soon as we can and coordinate a fix before any public discussion.

**Never commit** secrets, `.env` files, production database URLs, or member PII in issues or pull requests.
